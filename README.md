# 💼 Jobify - Job Portal Application (Frontend)

**Jobify** is a modern, responsive, and user-friendly Job Portal web application where job seekers can search and apply for jobs, and employers can post and manage job listings. This repository contains the **Frontend (Client-side)** source code of the project.

---

## 🚀 Tech Stack

- **Framework:** React.js (Powered by Vite for fast development and bundling)
- **Code Quality:** ESLint (Configured for clean and standardized code)
- **Package Manager:** npm

---

## 🛠️ Key Features

- **User Authentication:** Secure Login and Registration interfaces for users.
- **Interactive Dashboard:** Seamless navigation to track jobs, applications, and profile statistics.
- **Job Management:** Comprehensive layout to search, filter, and view individual job details.
- **Fully Responsive UI:** Optimized layout that works smoothly across Mobile, Tablet, and Desktop screens.

---

## 💻 Getting Started

Follow these steps to set up and run the frontend application locally on your machine.

### Prerequisites

Ensure you have **Node.js** (v18 or higher recommended) installed on your system.

### Installation Steps

1. **Navigate to the Project Directory:**
   ```bash
   cd fe-fsdcwee4142-jobify
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

4. **Start the Development Server:**
   ```bash
   npm run dev
   ```

Once started, the application will typically be accessible in your local browser at: **`http://localhost:5173`**
